# 姑娘

<div style="text-align: center;">
  **现代，雷达**
</div>
<br/>
<div style="text-align: center;">
在我23岁的年纪，姑娘，是最美好的词汇。

这段时间，我似乎无时无刻不在心里想着，嘴里念叨这词。

姑娘，姑娘，多么美好的称谓。

和手淫不一般，性欲，虽也是本能，可仅仅通过性幻想很难完成这个行为，这依赖某种实体。

但姑娘，姑娘，你要相信我是纯洁的，只需要想着这两个汉字，汉字，就能够心情愉悦。

我在琢磨姑娘的这段日子，停止了手淫。

直到现在，我仍然无法解释：

我混沌，肮脏，下流如化粪池般的语言系统是如何留下姑娘这美好的词汇而不排异。
</div>
